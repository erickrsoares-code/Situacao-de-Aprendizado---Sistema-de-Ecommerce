# 🛒 TechMarket - Sistema de E-commerce e PDV

Este projeto é um sistema de gerenciamento de supermercado (PDV) e e-commerce desenvolvido em Python. Ele utiliza **Programação Orientada a Objetos (POO)** para as regras de negócio e **Flask** para a interface web, entregando uma experiência de usuário fluida e responsiva.



## ⚙️ Funcionalidades Implementadas

*   **Autenticação Restrita:** Tela de login validando credenciais administrativas (`admin`/`admin`).
*   **Vitrine / Loja (PDV):** Exibição do catálogo de produtos com verificação de disponibilidade e botão de adicionar ao carrinho.
*   **Carrinho de Compras:** Resumo do pedido, cálculo automático do valor total, opção de remover itens e finalização de compra.
*   **Gestão de Estoque:** Ao finalizar uma venda, o sistema realiza a baixa imediata no estoque.
*   **Painel Administrativo:** Tela dedicada para o cadastro de novos produtos e alteração rápida de quantidades em estoque.



## 🚀 Como Executar o Projeto

Certifique-se de ter o Python instalado em sua máquina. O projeto foi estruturado para atender a duas formas de validação:

**1. Validação de Regras de Negócio via Terminal (POO)**
Para testar a criação de objetos e a lógica matemática de compras sem a interface web, execute
python main.py

**2. Flask""
python app.py
